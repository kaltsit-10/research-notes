## 一、近期完成的工作

### 1. ONNX 生态历史漏洞审计（已实证完成）

对 onnx 1.22.0 的三个漏洞高发区做了代码审计 + 实证攻击测试：

| 审计对象 | 对照历史 CVE | 结论 |
|---------|-------------|------|
| external_data 加载 | 7 条路径遍历 CVE（2022-2026） | **1.22.0 已全部修复**（../、绝对路径、symlink、hardlink 攻击全部被拦截） |
| version_converter | Gemm/Upsample 2 条 CVE（2026） | **已修复**（断言拦截，无内存崩溃） |
| onnx.hub 下载 | 2 条 CVE | **代码已整体移除** |

**结论**：onnx 包 11 条历史 CVE 在现装版本全部处置完毕。修复质量高（三层防御 + 内核级 openat2 + inode 对比 + TOCTOU 防护）。**找新漏洞必须靠新 fuzz，历史漏洞模式已无低垂果实。**

### 2. 打通"fuzz 真实 ONNX Runtime 引擎"（重大进展）

解决了 16 个环境/工具链障碍，成功从源码构建出带 **ASAN + 覆盖率插桩**的 onnxruntime fuzzer：

- `onnxruntime_proto_libfuzzer`：protobuf-mutator 结构化变异 + 真实 `Ort::Session` 推理
- 引擎库插桩验证通过：**覆盖率从 713 增长到 22535+，语料库持续积累**
- 关键修复：OSS-Fuzz 标准 sanitizer 配置、lld 链接器、ASLR 禁用、日志静默

## 二、重要发现（影响研究方向）

### 发现 1：ONNX Runtime 不公开发布 CVE

- ORT 的安全漏洞走 **MSRC 私密追踪**（VULN-#### 内部号），**不分配公开 CVE**
- 证据：issue #23258（1.19.2 崩溃）→ MSRC 确认 VULN-143188 → 1.20.1 修复，无 CVE
- GitHub 安全公告页为空（已实测确认）
- **含义**：fuzz ORT 出的 bug 报 MSRC，拿披露致谢 + 可能的赏金，但**没有 CVE 编号**作为成果
- 相比之下，**onnx 包（格式层）有完整的 CVE 发表流程**（14 条历史 CVE 即证明）

### 发现 2：onnx 包 2026 年新 CVE 集中在"版本转换器"

- CVE-2026-63632（Gemm 版本转换器堆越界读）、CVE-2026-44512（Upsample 版本转换器空指针）
- 这是我们 fuzz 尚未覆盖的代码区域 → 潜在的新 fuzz 目标
