## 二、上游 master 真实状态（git 证据）

复核基于本地仓库 `upstream/master = 946fe3f`（2026-08-18，与 #6922 base 一致）逐项核实：

| 检查项 | `git show upstream/master:src/net.cpp` 实测 | 判定 |
|---|---|---|
| header `layer_count/blob_count` | `if (layer_count <= 0 \|\| blob_count <= 0)`（TEXT:1327 / BIN:1708）——**仅非正校验，无上限** | 2^30 仍触发 `resize()` ~137GB OOM |
| per-layer `bottom_count/top_count` | grep `bottom_count < 0` / `invalid bottom_count` → **空** | 无守卫，负/巨大 count 直达 `resize()` |
| blob 索引 | grep `invalid bottom_blob_index` → **空** | 无守卫，索引裸用于 `d->blobs[idx]` |
| shape-hint 除零 | `const int psh_step = shape_hints.w / top_count;`（TEXT:1491 / BIN:1848）裸除 | `top_count=0` → FPE |

### ⚠️ afad533 合并状态核实（关键修正）

```bash
git merge-base --is-ancestor afad53357b60536b0a6d8f91fee83b7ae32dd22d upstream/master
# → NO  ⇒ afad533 不是 upstream/master 祖先，从未进入上游
git for-each-ref --contains afad5335...
# → 仅 refs/remotes/github/fix/blob-index-oob（fork 分支）
```

**结论**：`afad533`（2026-08-15，"fix out-of-bounds blob index..."）**只在 fork 分支
`fix/blob-index-oob` 上，从未合入上游 master**。上游在 946fe3f 上对 blob 漏洞**零防护**。

**连锁影响**（必须知悉）：
- 08-16 阶段总结"afad533 已合并"**为误记**（详见第六节）。
- CNVD 报送材料多处声明"afad533 已合并至 master / 已修复"——**前提不成立**，需修正（详见第五节）。
