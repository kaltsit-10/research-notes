# 国产具身智能组件「陌生 PR 友好度」调研 v2（2026-08-22，严谨版）

> **版本说明**：v1（08-20）仅凭 star 数与零散 PR 先例评级，未量化 PR 活跃度与外部贡献者比例，
> 导致 AimRT / 宇树 XR 被高估。经实测（GitHub API，2026-08-22）与用户实际挖掘反馈（AimRT/宇树 XR
> PR 少且多为内部提交），本版**逐仓库拉取最近 50 条 closed PR**，统计：
> 总 PR 数、外部作者数、外部合并数、PR 时间跨度、fix/security 类 PR 数，并核验外部作者身份。
>
> **方法论（可复现）**：
> 对每个仓库执行以下 API 调用（`{owner}/{repo}` 替换目标）：
> ```
> GET https://api.github.com/repos/{owner}/{repo}                          # 基本信息
> GET https://api.github.com/repos/{owner}/{repo}/pulls?state=closed&per_page=50&sort=updated&direction=desc
> ```
> 判定"外部贡献者"= `author_association` ∈ {CONTRIBUTOR, NONE, FIRST-TIME}（排除 OWNER/MEMBER/COLLABORATOR），
> 并人工核验作者是否为组织员工个人账号（多次提交核心 feature/test 的高频账号视为内部）。
>
> **验证入口**：各仓库 GitHub 页面 → `Pull requests` → `Closed` 标签页，可按作者/时间筛选复核本报告数字。

## 二、关键核验：AimRT / 宇树 XR 为什么被降级（用户实测的印证）

### AimRT（智元）——"外部 PR"多是内部员工个人账号

实测最近 50 条 closed PR 中，所谓"外部作者"高频出现：

| 作者 | 出现次数 | 性质判断 |
|---|---|---|
| `owny990312` | 多次 | 反复提交 mqtt/executor/test 报告等**核心功能** → 疑似智元员工 |
| `s1mplezy` | 多次 | 反复提交 header/plugin 等**核心架构** → 疑似智元员工 |
| `tqolf` | 1 | NONE 关联，fix RPC timeout（唯一像外部） |

→ **真正陌生贡献者占比很低**，且仓库最后推送 2026-04-29（**近 4 个月未更新**）。
验证网址：https://github.com/AimRT/AimRT/pulls?q=is%3Apr+is%3Aclosed

### unitreerobotics/xr_teleoperate（宇树 XR）

- 最近 50 条 closed PR 只有 **21 条**（总量小），时间跨度 2024-11 ~ 2026-08（近 2 年仅 21 条）；
- fix 类 7 条均为**功能修复**（logging/camera 参数），**无安全修复先例**；
- 验证网址：https://github.com/unitreerobotics/xr_teleoperate/pulls?q=is%3Apr+is%3Aclosed

### unitreerobotics/unitree_ros2（宇树 ROS2）

## 五、给用户的下一步建议

1. **首选 alibaba/MNN**：证据最强（外部合并率 98%、当天活跃、27 条 fix 先例、与 NCNN 同构方法论可复用）；
