## 十、目标评估与证据（2026-08-06 深度查证，含修正）

> ⚠️ **修正记录（用户质疑后复核）**：初版把 MindSpore/NCNN 评为"蓝海"是**错误**的——
> 它们是热门、被认可、被活跃研究的组件。搜不到近期研究 ≠ 没人研究（逻辑错误）。
> 修正后：这些组件属于导师说的"**被认可**"路线（而非蓝海），机会是"复现已知漏洞+找变体"而非"捡漏"。

### 评估框架（修正后）
```
蓝海（真没人挖）：国产世界模型（攻击方向），但需 GPU
被认可（热门、有 CVE 流程、有安全团队）：MindSpore / NCNN / 飞桨 —— 导师明线选项
被认可（有学术 fuzz、漏洞偏认证类）：Milvus
```

### 逐个评估（证据）

| 组件 | 类型 | 证据 | 机会 |
|------|------|------|------|
| **MindSpore** | 被认可（热） | ① 中国新增市场 **30%**；② 官方安全团队 + Majun 扫描；③ 近期 CVE：2023(CVE-2023-2970)、2025(CVE-2025-3144/3145)；④ **Valhalla 静态审阅 #021（2026-08-05）13 条告警全在核心路径**，明确建议"C++ 内存安全需专项审计"；⑤ 未修 DoS（44B→37GB，2.8.0） | **复现 DoS + 按 Valhalla 指出的缺口做专项审计** |
| **NCNN** | 被认可（热） | ① CVE-2026-50144（负 ID 堆越界）；② fuzz 发现 96B NULL 解引用（paramdict.cpp 系统性缺 empty() 检查，5 处不对称）；③ 有人 2026 年 fuzz | **复现 96B PoC + 系统性补审 paramdict** |
| **PaddlePaddle** | 被认可 | ① CVE 历史最丰富；② Critical RCE（pickle 9.8） | 复现 + 对照 |
| **Milvus** | 被认可 | ① 学术 fuzz（VDBFuzz）；② CVE-2026-26190（9.8 认证绕过）——偏 Go 认证类 | 需转技能，非首选 |
| llama.cpp/Ollama/vLLM | 被认可（国际） | OSS-Fuzz + Pwn2Own + 大量 CVE | 竞争激烈 |
| 国产世界模型 | **蓝海** | 公开攻击研究为零 | 需 GPU |

### 结论（修正后）
```
导师原话"被认可（或者还处于蓝海的）"→ 两条路都成立：
  被认可路：MindSpore / NCNN —— 复现已知漏洞→blog/CVE，找 Valhalla/paramdict 指出的缺口变体
  蓝海路：国产世界模型攻击 —— 需 GPU，留大四
```

### 交叉验证结论（08-07 更新）
1. **已复现的硬事实**：MindSpore DoS（32B→40GB）、**MindSpore CWE-787 堆溢出（变体审计新发现，dims=[2]+256B 内容）**、NCNN 96B NULL 解引用（master 仍崩溃）、NCNN CVE-2026-50144（漏洞版越界写 / master 已修）
2. **最大机会（更新）**：**MindSpore 堆溢出**（CWE-787，最新版未修 + 内存破坏 > DoS）和 NCNN 96B NULL 解引用（master 仍崩溃）→ 两个可上报新漏洞
3. **MindSpore DoS 最新版 2.10.0 仍未修**（2.8.0 已证存在）→ 可上报华为/CNVD
4. **已撤回的错误**：蓝海判断（MindSpore/NCNN 是"被认可"非蓝海）
5. **OSS-Fuzz 确认**：4 国产组件均不在 OSS-Fuzz（Google 官方 introspector）
6. **CNVD 空白确认**：MindSpore DoS/堆溢出、NCNN 96B/CVE-2026-50144 均无 CNVD/CNNVD 编号 → 上报 CNVD 是真实空白
