## 调研笔记：NCNN（2026-08-06 初步查证）

- **CVE-2026-50144**（近期！）：`ParamDict::load_param()` 堆越界写，参数 ID 只查 `id >= NCNN_MAX_PARAM_COUNT` 不查负值 → 负 ID 越界写堆 → 可能 RCE（CVSS 7.1，CWE-129/787）
- 触发路径：`Net::load_param()` 加载恶意 `.param` 文件
- 影响 commit e54f7b1 及更早；修复 5a0288f2
- **评估**：2026 年还在出堆溢出 → 模型解析层审计不充分，蓝海

## 调研笔记：PaddlePaddle（2026-08-06 初步查证）

- **Critical RCE（CVSS 9.8）**：`paddle.load()`（io.py）直接用 `pickle.load()` 无限制 → 恶意 `.pdparams` → 任意代码执行（CWE-502），PoC 已成功
- 历史 PDSA 系列：堆溢出（repeat_interleave/trace）、UAF（diagonal）、OOB read（gather_tree）、命令注入（convert_shape_compare/_wget_download/fs.py）
- **评估**：漏洞最丰富（有 CVE 历史可参照），但被挖得多 → 蓝海度中，审计对照价值高

## 调研笔记：MindSpore（2026-08-06 初步查证）

### 已知漏洞（未修复，可复现）
- **`load_checkpoint()` DoS**（CWE-789，CVSS 7.5）：
  - 44 字节 .ckpt → 触发 ~37.3GB 内存分配（放大率 ~9 亿倍）
  - 路径：`serialization.py::_load_into_param_dict` → C++ `ConvertBytesToTensor()`（tensor_py.cc）
  - 根因：protobuf `dims` 字段不校验是否匹配实际数据大小
  - 影响 2.8.0 及所有版本，供应链攻击面（HuggingFace/ModelScope 投放恶意模型）
  - **PoC 在 HuggingFace 上**（可复现 → 第一个报告候选）

### CVE 历史（证明有 CVE 流程——关键！）
- CVE-2021-33647~33654：Tile/Transpose/SparseToDense 堆溢出 + DepthwiseConv2D/Reduce/SpaceToBatch/Split 除零（360 AIVul 团队）
- 第三方依赖 CVE 追踪中（Python/Pillow/NumPy/openssl）

### 官方自认风险（SECURITY.md）
- 反序列化模型可加载执行恶意代码
- Lite 非法值（无效向量偏移）→ 段错误

### 结构（与 ONNX 技能同构）
`.ckpt` = protobuf → `load_checkpoint` 反序列化 → 张量分配 → 算子执行
→ 你的 ONNX fuzz + 攻击面分析技能**直接迁移**

### 战略价值
- **发 CVE**（不像 ORT 走 MSRC 无 CVE）→ 有明确成果出口
- 已知 DoS 未修 + 算子区有历史 CVE → 有挖掘空间
- 蓝海（外部审计少，360 2021 年挖过 Lite 后少人跟进）

## 世界模型攻击研究现状（2026-08-06 查证）

**结论：是活跃研究区（不空），但国产世界模型少人攻。**

### 2026 年代表工作
| 论文 | 攻击类型 | 目标 |
|------|---------|------|
| BadWorld (2606.16519) | 对抗图像 → 预测崩溃/失去控制一致性 | 自回归视觉世界模型 |
| BadDreamer (2606.21172) | 时空后门（5% 污染帧）→ 幻觉干净道路，92.5% ASR | 自动驾驶视频世界模型 |
| Targeting World Models (2606.09499) | 数据投毒：视觉提示劫持 + 状态转换劫持 | 机器人学习流水线/VLA |
| Oracle-Level Integrity (2606.22966) | PGD 攻击"可信想象"（imagined trajectory） | imagine-then-act VLA（RynnVLA/LingBot） |
| RoboTrustBench | 基准：视频世界模型可信度 | 机器人操作 |

### 空白点（用户机会）
- **国产世界模型少人攻**：书生 S01-Open、可灵 Kling、智元世界模型 —— 公开攻击研究几乎为零
- 现有攻击多针对国际模型（GAIA/UniSim/Genie）→ 换国产模型 + 你的 FGSM/CHAI 技能 = 潜在新工作
- 注意：这方向**竞争较激烈**（2026 年爆发），且需要 GPU 验证 → 比软件漏洞方向更难快速产出

### 战略权衡（软件漏洞 vs 模型攻击）
```
软件漏洞方向（MindSpore/NCNN/飞桨）：
  ✅ 可复现 PoC（DoS/RCE）→ 可直接写 blog（导师要的产出）
  ✅ 有 CVE 流程 → 成果出口明确
  ✅ CPU 可做（fuzz + 审计）
  ✅ 蓝海（近期才被挖）

世界模型攻击方向：
  ⚠️ 竞争激烈（2026 论文爆发）
  ⚠️ 需要 GPU 验证
  ⚠️ 产出周期长（要复现+新意）
  ✅ 导师明确提到 → 方向有战略价值
```
